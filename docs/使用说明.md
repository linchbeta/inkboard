# InkBoard 使用说明

整套东西分三部分：墨水屏本身（ESP32 开发板加一块墨水屏），它每隔一段时间醒来取一张画面，显示完就睡觉；后端，跑在 NAS 或电脑上（就是仓库里的 `server` 文件夹），负责把画面生成好；还有一个网页后台，用浏览器打开后端的地址，就能管理屏幕和要显示的内容。

现在主要用的两块屏：

| 屏幕 | 分辨率 | 颜色 |
|---|---|---|
| 3.98 寸 SE0398NZ07 | 768×552 | 黑、白、黄、红 |
| 4.2 寸 HINK SSD1683 | 400×300 | 黑、白、红 |

3.98 寸的 A0 和 A1 两个版本都实测过，5.83 寸三色屏（UC8179，648×480）在 WROOM-32E 板子上也实测过。上游 InkSight 支持的其它屏（4.2 寸黑白黄红、7.5 寸三色、各种黑白屏）固件也能用，同样有本地日历，只是没在真机上验证；2.9 寸没有适配。完整列表见[固件说明](../firmware/README.md)里的"支持的屏幕"。

## 一、部署后端

后端要一直开着，墨水屏才取得到画面，所以最好放在 NAS 上。

### 放在 NAS 上（Docker）

把 `server` 文件夹拷到 NAS，在这个文件夹里执行 `docker compose up -d --build`。等它跑完，浏览器打开 `http://NAS的IP:8080`，看到"创建管理员"的页面就说明好了。

如果启动时报 `port is already allocated`，说明 NAS 上 8080 端口已经被别的程序用了。在 `docker-compose.yml` 旁边新建一个名为 `.env` 的文件，里面写一行 `INKBOARD_PORT=8090`（8090 可以换成任意没被占用的端口），再执行一次上面的命令，之后后台和屏幕都用新的端口访问。

数据都在 `server/data/` 里，平时备份这个文件夹就行。

### 放在 Windows 电脑上

先装 [Node.js](https://nodejs.org/)，22.5 以上，推荐 24 LTS。然后在 `server` 文件夹里打开 PowerShell，执行：

```powershell
npm install
npm run build; npm start
```

第一次运行时 Windows 防火墙会弹窗，勾上"专用网络"，点允许。本机用 `http://localhost:8080` 就能打开后台；墨水屏要用电脑的局域网地址，在 PowerShell 里运行 `ipconfig`，找"IPv4 地址"那一行，比如 `http://192.168.1.10:8080`。

电脑睡眠或者关机的时候，墨水屏会一直显示最后那张画面，等后端恢复了再自动更新。

### 想在外面也能用（HTTPS）

后端本身只提供 HTTP（8080 端口）。要从外网访问，就在 NAS 或路由器上配一个反向代理（Caddy、Nginx，或者宝塔、1Panel 里的"反向代理"都行），把 `https://你的域名` 转到 `http://后端IP:8080`。配网时服务器地址填 `https://你的域名`。

证书用常见的就行：Let's Encrypt（Caddy、certbot、宝塔、1Panel 默认都是它）、DigiCert、Sectigo、ZeroSSL、GlobalSign、GoDaddy、谷歌（Cloudflare 用的）、亚马逊这些墨水屏都认，云服务商送的免费证书一般也是这几家签的。自己签的证书不行。

画面没变的时候，后端只回一个很小的"没有变化"，屏幕既不下载也不刷新，很省流量。反向代理别对后端的返回做压缩，也别改 `ETag`，默认配置一般都不会动这些。

### 第一次打开后台

第一次打开会让你建一个管理员账号，用户名随意，密码至少 6 位。以后每次打开都要先登录。

## 二、刷固件

一块屏只需要刷一次，以后更新固件时再刷。电脑上要先装好 [PlatformIO](https://platformio.org/)，装成 VS Code 插件就行。

用 USB 线把开发板接到电脑上，在 `firmware` 文件夹里打开 PowerShell，按屏幕型号运行对应的那一行：

```powershell
$pio = "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe"
& $pio run -e epd_398_se0398nz07a0_c3_promini -t upload     # 3.98 寸屏
& $pio run -e epd_42_hink_ssd1683_c3_promini -t upload      # 4.2 寸屏
```

3.98 寸屏如果排线上印的是 A1，就用 `epd_398_se0398nz07a1_c3_promini`。最后看到 `[SUCCESS]` 就是刷好了。

如果上传失败、提示找不到串口：按住板子上的 BOOT 键，按一下 RESET，松开 BOOT，再运行一次。同时插着好几块板子时，在命令后面加上 `--upload-port COM5` 指定是哪一个，串口号在设备管理器的"端口"里能看到。

没装开发环境的电脑也能刷：把编译好的 `firmware_merged.bin` 用 [ESP 网页刷机工具](https://espressif.github.io/esptool-js/) 从地址 `0x0` 烧进去就行，用 Chrome 或 Edge 打开。

## 三、配网

刚刷好固件的屏会自动进入配网模式：LED 常亮，屏幕上写着要连哪个热点、打开哪个网址。

1. 手机连上 WiFi 热点 `InkBoard-XXXX`。XXXX 是这块屏 MAC 地址的最后两段，有好几块屏时靠它区分。
2. 一般会自动弹出设置页面；没弹出来的话，用浏览器打开 `http://192.168.4.1`。
3. 在列表里点家里的 WiFi，输入密码。列表里没有的话，点"手动输入网络名称"。
4. "服务器地址"填后端的地址，比如 `http://192.168.1.10:8080`。
5. 点"连接"，等十几秒。成功后页面上会显示一个配对码，屏幕自动重启。

墨水屏只能连 2.4GHz 的 WiFi。路由器 2.4G 和 5G 用同一个名字一般没问题，实在连不上就在路由器里单独开一个 2.4G 的网络。

以后要换 WiFi 或者改服务器地址：按一下 RESET，松手后马上按住 BOOT，等 LED 常亮就进了配网模式。配网页里最多能存 5 个 WiFi，开机时按顺序挨个试；不在身边的网络（比如办公室、手机热点）也可以先"只保存"下来。

### 不联网，只当日历用

没有 WiFi，或者就想要一个日历的话，可以完全不联网。在配网页最下面点"只当日历用"，屏幕马上显示今天的日历，时间用的是这台手机的时间，不需要外网。在配网模式下短按一下 BOOT，或者 10 分钟没人操作，也会直接显示日历。

之后屏幕每天零点过后醒来翻到新的一天，别的时间都在睡，非常省电。这份日历和联网时服务器画的完全一样，农历、节气、节日、法定节假日的休和班都有。以后想联网，按 RESET 后按住 BOOT 进配网模式，把 WiFi 设置好就行。

说一下时间：开发板上没有专门的时钟晶振，长时间不联网时间会慢慢走偏，一天最多差几分钟，联网时会自动测出偏差并修正。每次打开配网页或者联网一次，时间就重新对准了。换电池或断电后，时间会回到上次保存的日期（最早是 2026 年 10 月 1 日），联网或者打开一次配网页就能对准。

## 四、把屏绑定到账号

后台只有一个账号的话，新屏会自动归到这个账号下，什么都不用做，刷新一下概览页就能看到。

有好几个账号时，新屏会显示一个 6 位的配对码，就是配网成功时页面上那个。登录自己的账号，在"概览"里点"添加设备"，输入配对码就绑定好了。

绑定以后只有你能看到和设置这块屏。不想要了，可以在这块屏的"设备"页面里解绑，屏幕会重新显示一个配对码。

## 五、设置一块屏

在"概览"里点某块屏的"内容"或"播放"（直接点画面也行）。每块屏有三个页面。

### 播放：显示哪些布局

播放列表决定这块屏轮流显示哪些布局，比如日历、天气、待办，从布局库里挑，可以选好几个。轮播的方式可以是顺序、随机（每一轮里每个布局只出现一次，不会连着重复），或者只显示第一个；多久换一个也能选，每次刷新都换，或者隔一段时间换。

某个布局可以只在特定时间段显示，比如早上 7 点到 8 点显示天气，还能限定只在工作日或周末。设了时间段的布局，到了那个时间段会优先显示。

想让某个布局马上出现，用"临时显示"：显示一次、一小时、三小时、到今天结束，或者一直显示到你取消。

刷新时间分白天和夜里分别设置，刷新得越少越省电。屏幕醒来的时间会对齐到整点，比如每 15 分钟一次的话，就在每小时的 0、15、30、45 分过半分钟刷新。

改好的播放列表可以一键复制给其他屏。

### 内容：每个布局显示什么

这里把播放列表里的布局逐个列出来，左边是这块屏上的预览，右边是设置。

- 待办作业：可以改标题，按人分组（比如每个孩子一组）。点"编辑清单"打开编辑器，打勾、调顺序、增删都在网页上做。
- 倒数日：生日、纪念日、考试、下个假期等等，支持农历和每年重复，可以挑一个用大字显示。
- 日程：订阅日历的 ICS 链接（Google、iCloud、Outlook、飞书等都有），也可以手动写。
- 课程表：小学到大学都能用。选好学段会自动套用常见的作息时间（高中带早读和晚自习），也可以自己写作息。中小学每天一行，按节次写课程；大学每门课写一行，写上第几节、教室和周次（单双周也行），填了开学日期还会显示现在是第几周。可以看整周，也可以只看当天，正在上的课和下一节课标成红色。周末、放假时自动显示下一个上学日，调休上课可以单独写一行。
- 看板：一屏看全，左边是日期、农历和天气，右边是最新留言、今天的日程和没做完的待办，这些内容都取自这块屏的留言、日程和待办设置。下面还有空的话，会显示离下个假期还有几天，再加一句一言。
- 一言：每次刷新换一句话，来自 hitokoto.cn，有动画、文学、诗词、影视、哲学等类别可选，也可以只要短句或长句。
- 留言板：显示写给这块屏的留言。
- 相框：播放相册里的全部照片，或者只播放勾选的几张。可以选带画框还是满屏，顺序、随机还是固定一张，多久换一张。4.2 寸这种直角屏还能给照片加圆角；3.98 寸屏本身就是圆角，照片跟着它走。
- 天气和日期牌：设置这块屏所在的城市。
- 古诗词：共约 480 首（常见的课本诗词，加上唐诗三百首、千家诗里的律诗和绝句）。每次刷新换一首（按季节挑，逢节日会穿插应景的诗），或者每天一首，或者固定显示某一首。还有个"换一首"按钮。
- 外语单词：英语、法语、德语、西班牙语、意大利语、葡萄牙语、日语和韩语都有。英语可以选人教版课本（小学三年级到高中，按册，带例句），也可以选中考、四六级、考研、专四专八、托福、雅思、SAT、GRE、GMAT、BEC 或者 COCA 常用词；日语有 JLPT N5 到 N1，带假名读音；每种语言都有常用词和进阶词。查词可以用有道（中文释义）、Free Dictionary（英英释义）、MyMemory 翻译，或者你自己的接口。也可以用网上的词表链接，或者自己写一份单词表，比如课本单元的单词。每次刷新学一个新词，或者每天一个；课本按课文顺序来，其它词库打乱。学过的词会按遗忘曲线在第 1、2、4、7、15 天出现在下面的复习栏里，标题上会显示学到了第几个。
- 行情：填股票、指数、黄金或者汇率的代码。
- 资讯：填 RSS 订阅地址。
- 日历、年度进度、月相黄历不需要设置。

每块屏的内容是各管各的，在这块屏上改待办、倒数日，不会影响别的屏。

如果几块屏要显示同一份内容，比如客厅和厨房想看同一个待办清单，就在这个布局卡片底下打开"多屏同步"，勾上其他屏保存。勾上的屏会改成显示这块屏的内容，以后在任意一块上修改，整组一起变。取消勾选的屏会保留当时的内容，之后各改各的。同步是按布局分开的，所以可以待办同步，照片各放各的。

### 设备：名称、方向、字体、电量

可以给屏起个名字，比如客厅、书房；不起的话就叫"3.98 寸屏""4.2 寸屏"。

屏幕方向：横着放就选"横向"；想竖着放，选"纵向"，再把屏逆时针转 90° 竖起来，每个布局都会换成竖版。排线朝上倒着放的话，选对应的"倒置"。屏幕下次刷新后生效，断网时的离线日历也会跟着转过来（配网画面始终是横的）。在"布局库"里切到"竖版"，可以先看看各个布局竖着是什么样子。

留言、诗词、倒数日这些页面里的大字，默认用霞鹜文楷，也可以换成思源黑体；4.2 寸屏还可以选点阵字体。

插着 USB 电源时可以打开实时模式，屏幕就不睡了。这一页还能看到最近 7 天的电池电压曲线、WiFi 信号和 MAC 地址。最下面是解绑，解绑后屏幕回到没绑定的状态，显示新的配对码。

## 六、其它页面

菜单是按用得多少排的：概览、留言、待办、相册、布局、设置。手机上底部放前五个，设置在右上角。

概览里能看到所有屏现在的画面、电量和下次什么时候刷新，也能直接写留言、添加设备。

布局库展示了所有布局的样子，可以一次把某个布局加到好几块屏的播放列表里，或者临时显示一下。

相册用来上传照片，手机上直接选图就行，会自动缩小。照片还能编辑，裁剪、旋转、调亮度和饱和度都可以，右边会实时显示在两种屏上抖动后的效果。每块屏放哪些照片，在那块屏的"内容 → 相框"里选。

留言页面写留言时，勾上要发给哪些屏。勾了"立即显示"，这些屏下次醒来会显示 3 个小时的留言板。

待办页面顶部可以切换屏幕，编辑每块屏的清单，在手机上打勾很方便。

设置里可以改密码，管理员还能管理家人的账号、节假日数据和测试日期。

### 多个家人账号

管理员可以在"设置 → 用户"里添加账号。每个账号有自己的屏、照片和留言，彼此看不到。家人登录自己的账号后，用配对码绑定自己的屏。

## 七、按键和指示灯

按一下 RESET，屏幕马上醒来刷新。按完 RESET 立刻按住 BOOT，等 LED 常亮，就进了配网模式，可以改 WiFi 或服务器地址。配网模式下短按一下 BOOT，就跳过配网，直接显示日历。

LED 常亮是在配网模式，10 分钟没人操作会改成显示日历；慢闪是正在连 WiFi；亮一秒后熄灭说明刷新成功，接着就睡了；快闪五下是失败了，WiFi 或后端连不上，到下次刷新时间会自己再试。

## 八、常见问题

**屏幕一直显示配对码**

后台有多个账号时需要手动绑定。登录后在"概览"里点"添加设备"，输入屏幕上的配对码。

**屏幕上提示要设置城市**

到这块屏的"内容"里，在天气或日期牌那一栏搜索并选好城市。

**断网了会怎样**

WiFi 或后端连不上时，屏幕会改成显示本地日历；如果收到过留言，会和最后一份留言板轮流显示。之后它会隔 15 分钟、30 分钟、1 小时这样越来越久地重新试着联网，最长 3 小时一次，但每天零点后一定会醒来翻日历。网络恢复后自动回到平常的播放列表。

**画面一直不更新**

先确认后端在运行，浏览器能打开后台。然后在"概览"里看这块屏的"上次刷新"时间，如果显示"已错过刷新"，说明它连不上后端。按一下 RESET 让它马上刷新，看 LED：快闪五下说明连接失败，检查 WiFi 密码和服务器地址，进配网模式重新设一下。用电脑当后端的话，还要看看电脑是不是睡着了，防火墙有没有放行 Node.js。

**后台改了设置，屏幕没反应**

屏幕在睡觉，要到下次刷新时才会去取新画面。想马上看到效果就按一下 RESET。

**换了路由器**

进配网模式重新选 WiFi。也可以提前在配网页里把新网络"只保存"下来。

**忘了密码**

管理员可以在"设置 → 用户"里重置别人的密码。管理员自己忘了的话，得到后端那台机器上改数据库，找负责维护的人处理。

## 九、备份和更新

备份就是复制 `server/data/` 这个文件夹，Docker 和电脑上都一样。

更新后端：用新代码替换 `server` 文件夹，`data` 留着别动，然后 Docker 上执行 `docker compose up -d --build`，电脑上执行 `npm install; npm run build; npm start`。

更新固件：照第二节重新上传一遍，保存的 WiFi 和服务器地址都还在。
