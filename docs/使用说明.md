# InkBoard 墨水屏 使用说明

InkBoard 由三部分组成：

1. **墨水屏**：ESP32-C3 开发板 + 墨水屏，定时醒来取一张画面显示，然后睡眠省电。
2. **后端**：运行在 NAS 或电脑上的服务（`server` 文件夹），负责生成画面。
3. **网页后台**：浏览器打开后端地址，管理屏幕、显示的内容和账号。

目前支持的屏幕：

| 屏幕 | 分辨率 | 颜色 |
|---|---|---|
| 3.98 寸 SE0398NZ07（A0；A1 版也支持，尚未实机验证） | 768×552 | 黑、白、黄、红 |
| 4.2 寸 HINK SSD1683 | 400×300 | 黑、白、红 |

固件还支持上游 InkSight 的其它屏（4.2 寸黑白黄红、5.83 / 7.5 寸三色、各种 4.2 / 5.83 / 7.5 寸黑白屏，尚未实机验证），都有本地日历；2.9 寸不适配。完整列表和每块屏对应的编译环境见 [固件说明](../firmware/README.md) 的「支持的屏幕」。

## 一、部署后端

后端要一直开着，墨水屏才能取到画面。推荐放在 NAS 上。

### 方式 A：NAS（Docker）

1. 把 `server` 文件夹复制到 NAS。
2. 在该文件夹里执行 `docker compose up -d --build`。
3. 浏览器打开 `http://<NAS 的 IP>:8080/`，能看到"创建管理员"页面就说明成功了。

数据保存在 `server/data/` 里，定期备份这个文件夹即可。

### 方式 B：Windows 电脑

1. 安装 [Node.js](https://nodejs.org/)（22.5 以上，推荐 24 LTS）。
2. 在 `server` 文件夹里打开 PowerShell，执行：
   ```powershell
   npm install
   npm run build; npm start
   ```
3. 第一次运行时 Windows 防火墙会询问，勾选"专用网络"并允许。
4. 浏览器打开 `http://localhost:8080/`。墨水屏要用电脑的局域网 IP 访问（在 PowerShell 里运行 `ipconfig` 查看"IPv4 地址"），
   例如 `http://192.168.1.10:8080`。

电脑睡眠或关机时，墨水屏会继续显示最后一张画面，等后端恢复后自动更新。

### 在公网使用（HTTPS）

后端本身只提供 HTTP（8080 端口）。要在外网访问，在 NAS 或路由器上用反向代理（Caddy、Nginx、宝塔 / 1Panel 的
"反向代理"等）把 `https://你的域名` 转发到 `http://后端IP:8080`，屏幕配网时服务器地址填 `https://你的域名`。

- **证书**：墨水屏认常见的公共证书机构：Let's Encrypt（Caddy、certbot、宝塔、1Panel 默认）、DigiCert / GeoTrust、
  Sectigo / ZeroSSL、GlobalSign、GoDaddy、谷歌 GTS（Cloudflare）、亚马逊等（云服务商的免费证书大多链到 DigiCert 或 Sectigo 的根）。自签名证书不行。
- **省流量**：画面没变时，后端只回一个很小的"未修改"，屏幕不下载也不刷新。反向代理不要对后端的回复做压缩或改写
  `ETag`（默认配置都不会）。
- 屏幕在 HTTPS 下也不会把画面写进 Flash：3.98 寸边下载边写进屏幕自带的显存，4.2 寸放在内存里。

### 第一次打开后台

第一次打开会要求创建**管理员账号**（用户名 + 至少 6 位密码）。之后每次打开需要登录。

## 二、刷固件

只需要做一次（以后更新固件时再做）。需要电脑上装好 [PlatformIO](https://platformio.org/)（VS Code 插件即可）。

1. 用 USB 线把开发板连到电脑。
2. 在 `firmware` 文件夹里打开 PowerShell，执行（3.98 寸屏和 4.2 寸屏各用一行）：
   ```powershell
   $pio = "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe"
   & $pio run -e epd_398_se0398nz07a0_c3_promini -t upload     # 3.98 寸屏
   & $pio run -e epd_42_hink_ssd1683_c3_promini -t upload      # 4.2 寸屏
   ```
   3.98 寸屏排线上印着 **A1** 的，用 `epd_398_se0398nz07a1_c3_promini`。
3. 最后出现 `[SUCCESS]` 即成功。

**上传失败、提示找不到串口**：按住板上的 BOOT 键，按一下 RESET，松开 BOOT，再运行一次命令。
同时插着几块板时，在命令末尾加 `--upload-port COM5` 指定串口（在设备管理器的"端口"里查看）。

没有开发环境的电脑，也可以把编译好的 `firmware_merged.bin` 用 [ESP 网页刷机工具](https://espressif.github.io/esptool-js/)
从地址 `0x0` 烧录（用 Chrome 或 Edge 浏览器）。

## 三、配网（让墨水屏连上 WiFi 和后端）

新刷固件的屏会自动进入配网模式：LED 常亮，屏幕上显示要连接的热点名称和要打开的地址。

1. 手机连接 WiFi 热点 **InkBoard-XXXX**（XXXX 是这块屏 MAC 地址的最后两段，用来区分不同的屏）。
2. 一般会自动弹出设置页；没有弹出的话，用浏览器打开 `http://192.168.4.1`。
3. 在列表里点选家里的 WiFi，输入密码。（WiFi 没出现在列表里时，点"手动输入网络名称"。）
4. "服务器地址"填后端地址，例如 `http://192.168.1.10:8080`。
5. 点"连接"，大约 15 秒。成功后页面显示**配对码**，屏幕会自动重启。

注意：墨水屏只支持 **2.4GHz** WiFi。路由器 2.4G 和 5G 用同一个名字时一般没问题；连不上时可以在路由器里单独开一个 2.4G 网络。

**以后要改 WiFi 或服务器地址**：按一下 RESET，松开后马上按住 BOOT，直到 LED 常亮，就进入了配网模式。
配网页里的"已保存的网络"最多存 5 个，开机按顺序尝试；还可以"只保存"现在不在范围内的网络（比如办公室、手机热点）。

### 不联网，只当日历用

没有 WiFi、或者只想要一个日历时，可以不联网：

- 在配网页最下面点 **「只当日历用」**：屏幕马上显示今天的日历，时间按这台手机对好（不需要外网）；或者
- 在配网模式下 **短按一下 BOOT**，或者 **10 分钟没人操作**：直接显示日历。

之后屏幕每天零点后自动翻到新的一天，其余时间都在睡眠，非常省电。日历和在线时服务器画的完全一样：农历、节气、节日、
法定节假日的「休 / 班」都有。以后要联网：按 RESET 后按住 BOOT 进入配网模式，设置好 WiFi 即可。

关于时间：开发板上没有专门的时钟晶振，长期不联网时间会慢慢走偏（每天几分钟以内，联网时会自动测出偏差并修正）。
每次进入配网页、或者联网一次，时间就会重新对准。换电池或断电后，时间回到上次保存的日期（至少 2026 年 10 月 1 日），
联网或打开一次配网页即可对准。

## 四、把屏绑定到账号

- **后台只有一个账号**：新屏自动归这个账号，不用做什么，刷新概览页就能看到。
- **有多个账号**：新屏会显示 6 位配对码（也就是配网成功时页面上的那个）。登录自己的账号，在「概览 → 添加设备」里输入配对码即可。

绑定后，这块屏只有你能看到和设置。不想要了可以在屏幕的「设备」页里"解绑"，它会重新显示配对码。

## 五、设置一块屏

在「概览」里点某块屏的「内容」或「播放」（也可以点画面）。每块屏有三个页面：

### 播放：显示哪些布局

- **播放列表**：从布局库里选这块屏要显示的布局（日历、天气、待办……），可以多个。
- **播放方式**：顺序轮播、随机轮播（每轮每个布局出现一次，不会连续重复），或只显示第一个。
- **换一个**：每次刷新换下一个，或每隔一段时间换。
- **时间段**：某个布局可以只在某段时间显示（例如早上 7:00–8:00 显示天气），可以限定工作日或周末。
  设了时间段的布局在那段时间优先显示。
- **临时显示**：让某个布局马上显示一次、1 小时、3 小时、到今天结束，或直到取消。
- **刷新时间**：白天每隔几分钟刷新、晚上每隔多久刷新。刷新越少越省电。屏幕按整点对齐醒来（例如每 15 分钟就在 :00、:15、:30、:45 过半分钟刷新）。
- **同时应用到其他屏**：把这个播放列表复制给其他屏。

### 内容：每个布局显示什么

这里列出播放列表里的每个布局，左边是这块屏上的效果预览，右边是设置：

| 布局 | 可以设置 |
|---|---|
| 待办作业 | 屏幕标题、分组（比如每个孩子一组）、事项；点"编辑清单"打开编辑器，打勾、调整顺序、增删都在网页上完成 |
| 倒数日 | 生日、纪念日、考试、下个假期……支持农历和每年重复，可以选哪一个用大字显示 |
| 日程 | 订阅日历的 ICS 链接（Google、iCloud、Outlook、飞书等），或手动添加日程 |
| 课程表 | 小学到大学：选学段套用常见作息（高中含早读、晚自习），也可自己写作息；中小学每天一行按节写，大学每门课一行写节次、教室和周次（单双周），填开学日期后显示第几周；整周或只看当天，正在上的和下一节课标红；周末、放假自动显示下一个上学日，调休上课可以单独写一行 |
| 看板 | 一屏看全：日期、农历、天气，加上最新留言、今天的日程和没做完的待办（内容取自这块屏的留言、日程、待办）；下方有空时显示下个假期还有几天和一句一言 |
| 一言 | 一句话（动画、文学、诗词、影视、哲学……，来自一言 hitokoto.cn），可选类别和长短；每次刷新换一句，长短句都自动排版 |
| 留言板 | 写给这块屏的留言 |
| 相框 | 播放相册里的全部照片或只播放勾选的照片；画框或满屏；顺序、随机或固定一张；换片间隔；圆角（4.2 寸等直角屏可选直角 / 小 / 中 / 大，3.98 寸屏跟随屏幕本身的圆角） |
| 天气 / 日期牌 | 这块屏所在的城市 |
| 古诗词 | 每次刷新换一首（应季，节日穿插应景的诗），或每天一首，或固定某一首；"换一首"按钮 |
| 外语单词 | 英、法、德、西、意、葡、日、韩语；英语有人教版课本词表（小学三年级到高中，按册，带例句）、中考、四六级、考研、专四专八、托福、雅思、SAT、GRE、GMAT、BEC 和 COCA 常用词，日语有 JLPT N5–N1（带假名读音），各语种都有常用词、进阶词；查词接口可选有道（中文释义）、Free Dictionary（英英）、MyMemory 翻译或自己的接口；也可用网上的词表链接或自己的单词表（比如课本单元单词）；每次刷新或每天学一个新词，课本按课文顺序、其它词库打乱；学过的词按遗忘曲线在第 1、2、4、7、15 天出现在复习栏；标题显示学到第几个 |
| 行情 | 股票、指数、黄金、汇率代码 |
| 资讯 | RSS 订阅地址 |
| 日历、年度进度、月相黄历 | 不需要设置 |

**每块屏的内容是独立的**：在这块屏上改待办、倒数日等，不会影响其他屏。

**多屏同步**：几块屏要显示同一份内容时（比如客厅和厨房显示同一个待办清单），在这个布局卡片底部打开「多屏同步」，
勾选其他屏并保存。勾选的屏会改为显示这块屏的内容，之后在任何一块屏上修改，整组都会一起更新。
取消勾选的屏会保留当前内容，之后各改各的。同步是按布局分开的：可以待办同步、照片各自不同。

### 设备：名称、字体、电量

- **名称**：给屏起个名字（客厅、书房……）。不起名时显示为"3.98 寸屏""4.2 寸屏"。
- **大字字体**：留言、诗词、倒数日等页面的大字用霞鹜文楷（默认）或思源黑体；4.2 寸屏还可以选点阵字体。
- **实时模式**：插着 USB 电源时可以打开，屏幕不睡眠。
- **电量与连接**：近 7 天的电池电压曲线、WiFi 信号、MAC 地址。
- **解绑**：屏幕回到未绑定状态，显示新的配对码。

## 六、其它页面

菜单按常用程度排列：概览、留言、待办、相册、布局、设置（手机上底部是前五个，设置在右上角）。

- **概览**：所有屏的当前画面、电量、下次刷新时间；快速留言；添加设备。
- **布局库**：所有布局的示例预览。可以一次把某个布局加入多块屏的播放列表，或临时显示一下。
- **相册**：上传照片（手机直接选图即可，会自动缩小），编辑照片（裁剪、旋转、亮度、饱和度等，右侧实时显示两种屏的抖动效果）。
  每块屏播放哪些照片在那块屏的「内容 → 相框」里选。
- **留言**：写留言并勾选发给哪些屏；勾选"立即显示"会让这些屏下次醒来时显示留言板 3 小时。
- **待办**：顶部切换屏幕，编辑每块屏的清单（手机上打勾很方便）。
- **设置**：修改密码、管理家人账号（管理员）、节假日数据、测试日期。

### 多个家人账号

管理员可以在「设置 → 用户」里添加账号。每个账号有自己的屏、照片和留言，互相看不到；
家人登录自己的账号后，用配对码绑定自己的屏。

## 七、按键和指示灯

| 操作 | 作用 |
|---|---|
| 按一下 RESET | 马上唤醒并刷新 |
| 按 RESET 后马上按住 BOOT，直到 LED 常亮 | 进入配网模式（改 WiFi 或服务器地址） |
| 配网模式下短按 BOOT | 跳过配网，显示日历 |

| LED | 含义 |
|---|---|
| 常亮 | 配网模式（10 分钟没人操作会改为显示日历） |
| 慢闪 | 正在连接 WiFi |
| 亮 1 秒后熄灭 | 刷新成功，进入睡眠 |
| 快闪 5 下 | 失败（WiFi 或后端连不上），到下次刷新时间会自动重试 |

## 八、常见问题

**屏幕一直显示配对码**
后台有多个账号时需要手动绑定：登录后在「概览 → 添加设备」输入屏幕上的配对码。

**屏幕显示"请在后台这块屏的'内容'里设置城市"**
在这块屏的「内容 → 天气（或日期牌）」里搜索并选择城市。

**断网了会怎样**
WiFi 或后端连不上时，屏幕改为显示本地日历；如果收到过留言，会和最后一条留言板轮流显示。之后隔 15 分钟、30 分钟、1 小时……
（最长 3 小时）再试着联网，但每天零点后一定会醒来翻日历。联网恢复后自动回到正常的播放列表。

**画面一直不更新**
- 确认后端在运行：浏览器能打开后台。
- 在「概览」看这块屏的"上次刷新"时间；显示"已错过刷新"说明屏连不上后端。
- 按一下 RESET 立即刷新，观察 LED：快闪 5 下说明连接失败，检查 WiFi 密码和服务器地址（进入配网模式重新设置）。
- 电脑当后端时，检查电脑是否睡眠、防火墙是否允许 Node.js。

**后台里改了设置，屏幕没变**
屏幕在睡眠，到下一次刷新时间才会取新画面；想马上看到就按一下 RESET。

**换了 WiFi 路由器**
进入配网模式重新选 WiFi，或提前在配网页"只保存"新网络。

**忘记密码**
管理员可以在「设置 → 用户」里重置其他人的密码。管理员自己忘记密码时，需要在后端电脑上处理数据库（联系维护的人）。

## 九、备份和更新

- **备份**：复制 `server/data/` 文件夹（Docker 方式）或后端电脑上的 `server\data\`。
- **更新后端**：用新代码替换 `server` 文件夹（保留 `data`），Docker 执行 `docker compose up -d --build`，
  电脑上执行 `npm install; npm run build; npm start`。
- **更新固件**：按"二、刷固件"重新上传；保存的 WiFi 和服务器地址会保留。
